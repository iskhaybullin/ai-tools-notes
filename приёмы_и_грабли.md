# Приёмы и грабли

## VPN и сайты .ru
- При включённом VPN российские сайты могут не открываться или работать с ошибками.
- Решение: добавить их в исключения AdGuard VPN, чтобы они открывались напрямую.
- Что добавлять в исключения: например, российские сайты, которые не открываются через VPN.

## Vercel: сначала превью
- `vercel` без `--prod` публикует превью, то есть отдельную тестовую ссылку. Основной сайт при этом не меняется.
- `--prod` добавлять только после того, как проверил превью.

## Лендинг должен быть автономным
- Стили, шрифты и скрипты держать внутри проекта, не грузить их с чужого домена.
- Иначе, если чужой сайт ляжет, сменится или будет заблокирован, лендинг развалится.

## Git: один проект — один репозиторий
- Не делать `git init` в общей папке, где лежат несколько проектов.
- Иначе история проектов перемешается, в коммиты попадёт лишнее, и откатить один проект, не задев другие, не получится.
- Git включать внутри папки конкретного проекта.
