# Шпаргалка Claude Code

Команды со слешем (`/clear` и т. п.) пишутся в поле ввода Claude.
Остальные (`cd`, `claude`) пишутся в обычном терминале.

## Запуск и выход

| Что | Зачем |
|---|---|
| `cd "путь/к/папке"` | Перейти в папку проекта. Claude работает с той папкой, откуда его запустили. |
| `claude` | Начать новую сессию. |
| `claude --continue` | Продолжить последнюю сессию в этой папке. |
| `/exit` | Выйти из Claude. |
| `/login` | Войти в аккаунт или сменить его. |
| `/model` | Выбрать модель. |

## Разговор и экономия

- `/clear` — очистить разговор и начать с чистого листа. Ничего не стоит. Делай так перед каждой новой задачей.
- `/compact что сохранить` — сжать разговор в краткую выжимку. После команды напиши, что важно сохранить. Например: `/compact сохрани решения по лендингу и список того, что осталось`.
- `/autocompact` — настройка автоматического сжатия, когда контекст заполнен.
- `/usage` — сколько лимита израсходовано.
- **Строка состояния** внизу показывает, насколько заполнен контекст (память разговора). Если заполнено 50–60%, пиши итог в ЖУРНАЛ.md и делай `/clear`.
- **Одна задача — одна сессия.** Если мешать задачи, Claude путается и тратит лишние токены.
- **Не держи два агента на одной папке.** Они будут править одни и те же файлы и мешать друг другу.

## Режимы

`Shift+Tab` переключает режимы по кругу:
- **Обычный** — Claude спрашивает разрешения на правки и команды. Подходит, когда хочешь контролировать каждый шаг.
- **План** — Claude только изучает и предлагает план, ничего не меняет. Подходит для большой или непонятной задачи: сначала план, потом работа.
- **Авто** — Claude сам делает безопасные действия без вопросов. Подходит для понятной рутинной задачи.

Ещё:
- `Ctrl+G` — открыть план в редакторе, чтобы его поправить. Чтобы продолжить, закрой вкладку.
- Когда Claude предлагает меню с вариантами, выбирай цифрой.

## Поле ввода

- `Control+C` один раз очищает поле ввода, два раза подряд выходит из Claude.
- `Esc` останавливает Claude посреди работы.
- **«N lines selected»** — значит, к сообщению прикреплён кусок текста, выделенный в редакторе (VS Code). Чтобы убрать, сними выделение в редакторе: кликни в любое место файла.
- `!` перед командой выполняет её самому, без Claude. Например: `! ls`. Вывод команды попадёт в разговор.

## Скиллы и плагины

- `/plugin` — найти, установить и отключить плагины.
- `/skill-creator` — создать или улучшить свой скилл.
- `/inject <что>` — проверить скилл, плагин или папку на prompt-инъекции (спрятанные команды для ИИ).
- **find-skills** — скилл поиска готовых скиллов на skills.sh. Включается, когда прошу найти, подобрать или установить скилл.
- Где лежат скиллы:
  - глобальные, работают во всех проектах: `~/.claude/skills/`
  - локальные, только для одного проекта: `.claude/skills/` в папке проекта
- **Порядок установки чужого скилла:**
  1. Скачать во временную папку.
  2. Проверить через `/inject`.
  3. Если вердикт нормальный, установить простым копированием папки в `~/.claude/skills/`, без `npx`.

## Терминал или панель VS Code

- **Терминал** (отдельное окно) — отдельно от редактора, надёжно, и легко держать несколько сессий в разных папках. Подходит для долгих задач и когда редактор не нужен.
- **Панель в VS Code** — Claude видит открытый файл и выделенный текст, а правки удобно смотреть сразу в редакторе. Подходит, когда работаешь с файлами и хочешь видеть изменения.
